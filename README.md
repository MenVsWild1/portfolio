# MenVsWild — portfolio

Личное портфолио Тимофея Бойчука: Python backend, Telegram-разработка и серверная инфраструктура.

**Сайт:** https://menvswild.ru  
**GitHub:** https://github.com/MenVsWild1  
**Telegram:** https://t.me/Menvswild

## Основные направления

- Python backend: FastAPI, asyncio, SQLAlchemy, REST API, WebSocket.
- Telegram-разработка: aiogram, интеграции и автоматизация.
- Данные: PostgreSQL, PostGIS, Redis, SQLite.
- Инфраструктура: Linux, Docker Compose, Nginx, Caddy, systemd.
- Сети: TCP/IP, DNS, Xray.

## Проекты

- **AXIS VPN** — Telegram-сервис подписок и биллинга; более 850 успешных платежей за время работы. Проект передан новому владельцу.
- **ВПОИСКЕ** — backend поисково-спасательной платформы с геоданными и realtime-обновлениями.
- **WraithControl** — инструмент автоматизации Telegram Business.
- **Northstar Agent 2.0** — локальный AI-агент.
- **Job-Agent** — автоматизация поиска вакансий и подготовки откликов.
- **CinemaBot** — Telegram-бот с каталогом фильмов.
- **Telegram Lead Bot** — [исходный код](https://github.com/MenVsWild1/tg-lead-bot).
- **Web Parser → Excel** — [исходный код](https://github.com/MenVsWild1/web-parser-to-excel).
- **Network / DPI Lab** — [исходный код](https://github.com/MenVsWild1/dpi-test-submit).

## Разработка

Это статический сайт без сборщика и стороннего JavaScript-фреймворка. GitHub Pages публикует содержимое ветки \`main\` через GitHub Actions.

Основные файлы:

- \`index.html\` — семантическая разметка и карточки проектов.
- \`style.css\` — адаптивные стили.
- \`script.js\` — диалог с подробностями проектов и часы.
- \`favicon.svg\` — иконка сайта.
- \`1.jpg\` — аватар.
